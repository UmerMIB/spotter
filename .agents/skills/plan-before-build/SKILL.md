# Plan before build

1. Give 2 or 3 options. For each: how it works, cost, main risk.
2. Recommend one, but wait for the user to decide.
3. Write the plan: data model, job flow, failure cases, what we are building now and what we are skipping.
4. Split the plan into small slices. Name the first slice.
5. Wait for approval before writing any code.
